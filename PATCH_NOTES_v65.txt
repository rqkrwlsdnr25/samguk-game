삼국쟁패 v65 — 산둥반도 직결 해상 이동망 복구 / 수송선 이동 연출

기준 버전: v64 해상칸 제거 · 해상이동 유지

1. 직접 해상 인접망 복구
- 산둥반도 ↔ 한성 기존 연결을 명시적으로 유지
- 산둥반도 ↔ 웅진 서부 신규 직접 연결
- 산둥반도 ↔ 탕정성 신규 직접 연결
- 중간 SeaNode/정박칸 없이 WORLD.seaRoutes + WORLD.neighbors 양쪽에 런타임 설치
- 공격/지원/AI/보급/길찾기에서 동일한 neighbors 그래프를 사용하므로 별도 우회 로직 불필요

2. 상시 해상 표시 없음
- 바다 위 닻/해상칸/상시 점선 루트는 다시 만들지 않음
- 해상 대상이 실제로 선택되었을 때만 얇은 흰색 이동 가이드 표시
- 이동 애니메이션 종료 즉시 가이드/수송선 레이어 제거

3. 수송선 이동 스프라이트
- direct sea route 이동 중 기존 육군 깃발 대신 transport_ship.svg 사용
- 병력 수 HUD는 유지
- 육상 이동 애니메이션은 기존 그대로 유지

4. Canvas 호환 API
- drawActiveSeaMovementPath(ctx, fromRegion, toRegion, progress, currentZoom)
- SAMGUK_DIRECT_SEA_MOVEMENT.drawTransportUnit(...)

5. Java 서버 예제
- DirectSeaAdjacencyConfig.apply(Map<Integer, Set<Integer>>) 추가
- 산둥 ↔ 한성/웅진서부/탕정성 양방향 간선 등록
