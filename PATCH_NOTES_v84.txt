삼국쟁패 v84 - 항구도시 / 도시 이미지 복구 패치

기준: v83 1년 8턴 / 계절 / 병량 시스템 패치본

1) 항구도시 추가
- 기존 도시증축 시스템에 항구도시(port)를 4번째 전문도시로 추가.
- COASTAL 해안 영토에서만 항구도시 I 증축 가능.
- UI 비활성화뿐 아니라 실제 upgradeCityForCountry 함수에서도 해안 여부를 재검사.
- AI도 해안 영토에서만 항구도시를 선택할 수 있음.
- 저장/불러오기는 기존 regions[].cityType / cityLevel 구조를 그대로 사용.

2) 항구도시 밸런스
- Lv.I: 해당 영토 턴 수입 +25%, 해당 영토 병량 생산 +25%
- Lv.II: 해당 영토 턴 수입 +35%, 해당 영토 병량 생산 +35%
- Lv.III: 해당 영토 턴 수입 +50%, 해당 영토 병량 생산 +50%
- 병량은 기존 국가 단일 food 값에 합산되며 영토별 재고는 만들지 않음.
- 겨울 기본 생산량이 0이므로 항구도시도 겨울 신규 병량 생산은 0.

3) 도시 이미지 교체 / 오류 수정
- 누락되던 city_agriculture.webp / city_commerce.webp / city_military.webp 참조를 제거.
- 사용자가 제공한 PNG를 투명 배경 게임 리소스로 변환해 다음 파일로 적용:
  city_agriculture.png
  city_commerce.png
  city_military.png
  city_port.png
- index.html preload도 PNG 경로로 교체.
- 수도 Lv3 / Lv5 이미지를 사용자가 다시 제공한 파일로 교체하고 기존 투명 마스크 유지.

4) 기존 시스템 유지
