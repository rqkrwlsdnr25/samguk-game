[변경]
1. [① 인재 목록] 클릭 시 openMyOfficerListUI(event) 직접 호출.
2. 인재 목록을 표 형식에서 4열 장수 카드 그리드로 교체.
3. 화면에는 현재 플레이어 세력 소속 장수만 표시.
   - getPlayerOfficers()가 있으면 이를 최우선 사용.
   - 타국/미등용 전체 장수 목록을 카드 UI에 전달하지 않음.
4. 제공받은 금빛 비취 프레임을 hero_frame.png로 추가.
   - 흰 배경/중앙 영역은 투명 처리하여 초상 위 오버레이 가능.
5. 카드 3층 구조:
   - 초상
   - hero_frame.png
   - 병과 아이콘 / 이름 / 관직 / 영지 / 무력·지력·통솔·매력
6. 카드 클릭 시 기존 장수 상세창 openOfficerDetail() 연결 유지.
7. 현재 게임의 기존 SVG 장수 초상을 선명한 fallback portrait로 재사용.
   실제 장수 일러스트 에셋을 추후 연결해도 카드 레이아웃은 그대로 사용 가능.
8. 선택적으로 window.SAMGUK_MY_OFFICER_API_URL='/api/me/officers' 지정 시 Java API fetch 지원.
   API 실패 시 현재 게임 세션의 아군 인재로 안전하게 fallback.
9. Java 예제 추가:
   - MyOfficerListService.java
   - MyOfficerListController.java
   - playerFaction.getOfficers()만 직렬화하도록 구성.
