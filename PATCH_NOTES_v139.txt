[v139] 동진 남부 단색 가이드 정밀 재분할 / Gap 제거 / 경계 하천 보정

기준 버전
- v138 위 덮어쓰기

핵심 수정
1. 단색 가이드 기반 5개 영역 재구성
- 보라색: 동진 남부
- 핑크색: 동진 연안
- 빨간색: 동진 남동
- 주황색: 동진 강남 서부
- 초록색: 동진 강남 동부

2. Gap 제거
- 가이드 색상 마스크를 coverage partition으로 벡터화하고 공유 경계를 함께 단순화해
  인접 영토 사이의 1px 공백 및 민트색 삼각형 Gap이 남지 않도록 수정.
- 최종 5개 Polygon은 서로 면적 중복 0, union은 하나의 연속 Polygon.

3. 동진 남동 좌표 오류 수정
- 기존 선택 테두리의 계단형/절단형 경계를 폐기하고 빨간색 가이드의 실제 중앙 영역으로 재구성.

4. 동진 연안 / 동진 강남 동부 경계 재정의
- 핑크색 연안은 동쪽 해안까지 확장.
- 초록색 강남 동부는 하단/우측 영역을 빈틈 없이 채움.
- 우측 외곽은 가이드 외부를 Sea로 유지.

5. 하천 렌더링
- 핑크(연안) / 빨강(남동) / 초록(강남 동부) 삼거리 부근에서 시작해
  연안-강남동부 공유 경계를 따라 바다로 빠지는 Bezier river path로 갱신.
- map.js는 v139 데이터 우선 로딩 + 기존 v137 fallback을 지원.
