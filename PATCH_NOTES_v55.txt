삼국쟁패 v55 — 영토 라벨 히트박스 오버레이 제거

기준 버전
- v54 영토 정중앙 Centroid 전체본

실제 원인
1) map.js / territoryLabels()
- 확대 상태의 각 지역 라벨 스택에 큰 투명 SVG rect가 생성되고 있었음.
- 해당 rect는 pointer-events="all"이라 지역명/성/병력 HUD 주변의 사각형 영역을 별도 클릭 타깃으로 사용했음.
- 라벨 root 또한 role="button" + tabindex="0"이라 SVG Bounding Box가 포커스 가능한 UI 오브젝트로 취급됐음.

2) style.css
- .map-marker:hover rect 와 .map-marker:focus-visible rect 규칙이 marker 내부 rect에 stroke를 부여할 수 있었음.
- 위 투명 hit target 또는 fallback rect와 결합되면 지역 위에 사각형 외곽선이 드러날 수 있는 구조였음.

패치
- map.js의 투명 rectangular hit target 생성 코드를 삭제.
- territory label root의 role/button tabindex 제거.
- overlay marker/label stack에 pointer-events="none" 고정.
- style.css의 map-marker hover/focus rect stroke 규칙 제거.
- map-label-hitbox-disable.css 신규 추가: 오래된 DOM/핫리로드 상황에서 남아 있는 transparent rect도 display:none + pointer-events:none으로 하드 차단.

보존한 기능
- 실제 영토 Polygon(#map .territory-shape)의 hover/클릭은 유지.
- 한성 등 지역명 텍스트 유지.
- 수도/성/전문도시 이미지 유지.
- 세력 깃발 + 병력 HUD(예: 백 36) 유지.
- Centroid 정중앙 배치 유지.
- 지도 Pan/Zoom/GPU 카메라/Dirty Render 유지.
- 외교/전쟁/AI/도시/병력 수치 변경 없음.

성능 영향
- 지역 라벨마다 생성되던 투명 rect DOM 1개씩을 제거해 SVG hit-testing 대상도 감소.
- hover/focus 시 불필요한 rect paint/stroke invalidation을 제거.
