삼국쟁패 v134 — 일본 병합 잔선 제거 / 경계선 완전 통합 패치

기준 버전
- v132 기능 패치 + v133 index.html 긴급 복구가 적용된 상태

수정 내용
1. 시고쿠 내부 잔선 제거
- 기존 병합 path의 인접 sub-polygon 사이 0.36px 절단 간격을 실제 geometry union으로 메움.
- 긴 내부 세로 절편이 남지 않도록 merged polygon path를 재작성.
- 선택 시 Yellow Outline도 새 union path를 사용함.

2. 왜 북부 서부 / 왜 북부 중앙 세로 잔선 제거
- 왜 북부 서부 + 왜 동북부를 동일 소유일 때 하나의 fill pass로 합성.
- 왜 북부 + 왜 극동부를 동일 소유일 때 하나의 fill pass로 합성.
- 서로 다른 SVG path 사이 antialias gap / 구 세로선이 보이지 않도록 함.
- 실제 구분선은 산맥을 따라가는 가로 divider만 별도 렌더링.

3. 왜 동북부 / 왜 극동부 세로 절편 제거
- 각각 분리되어 있던 sub-polygon 사이 0.56px gap을 union하여 한 덩어리로 정리.
- x≈1022 부근의 세로 shared-edge 잔선을 geometry에서 제거.
- 상/하 구분은 기존 가이드의 가로 경계 path만 남김.

4. 렌더링 구조 정리
- 일본 특정 영역은 same-owner일 때 개별 shape fill 대신 seamless owner-fill layer를 사용.
- 구 vertical artifact border(x≈969.5, x≈1022.2)는 boundary layer에서도 필터링.
- 소유 세력이 달라질 경우에는 개별 영토 렌더링으로 복귀하여 전쟁/점령 시 경계를 구분할 수 있음.
