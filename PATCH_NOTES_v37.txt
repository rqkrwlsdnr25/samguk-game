삼국쟁패 v37 · 인사 / 인재 찾기 시스템

[메뉴]
- 영토 행동 메뉴에 "인사" 추가
- 인사 서브 메뉴: ① 인재 목록 ② 인재 찾기

[인재 목록]
- 플레이어 소유 전국 장수를 중앙 팝업으로 표시
- 이름 / 소속 영지 / 관직 / 무력 / 통솔 / 지력 / 매력 정렬
- 행 클릭 시 기존 장수 상세창 연결

[인재 찾기]
- 해당 영지에 인재소 필요
- 1회 50금, 행동력 소모 없음
- 등록 실패 시 50금 자동 환불
- 신규 인재는 기존 Officer/영지 인덱스/태수 시스템에 즉시 등록

[확률]
요청 수치 70+20+10+1+0.1=101.1%이므로 단일 획득 확률을 100%로 맞추기 위해
희귀 등급을 보존하고 인급만 68.9%로 보정:
- 인급 68.9%
- 지급 20.0%
- 천급 10.0%
- 신급 1.0%
- 선인급 0.1%

[능력치]
- 인급: 주력 58~70 (70 하드캡)
- 지급: 주력 76~83
- 천급: 주력 87~92
- 신급: 주력 93~97
- 선인급: 주력 98~100
- 주력 스탯에 따라 문관/무관 자동 분류

[연출]
- 인: 회백색 기본
- 지: 청록/청색 약한 광택
- 천: 보라 펄스
- 신: 황금 광휘 + 화면 진동
- 선인: 청백/오로라 + 암전 컷인 + samguk:personnel-sfx 이벤트

[건물]
- 인재소(人才所): 90금, 금 1/턴 유지비, 일반 영지 건설 가능
