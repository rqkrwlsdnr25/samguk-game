삼국쟁패 v121 — 전문도시 역할 재설계

목표
- 토성은 순수 수비, 군사도시는 공격/기동/장수 운용으로 역할 분리.
- 농업/상업/해상도시는 기존 병량·금·특산품·외교 시스템과 직접 연결.

구현 파일
- ProfessionalCityRules.js: 전문도시 modifier 단일 데이터 원본
- terrain-rules.js: 군사도시 출병 AP -1 (최소 1)
- unit-rules.js: 농업도시 모집 병량 -20%
- TurnEconomyManager.js: 농업 +50%, 해상 +25% 병량 생산
- resources.js: 상업도시 특산품 생산 x2
- DiplomacyTradeSystem.js: 해상도시 특산품 외교 교역가치 x1.5
- game.js: 금 수입, 군사도시 장수/공성 효과, 기존 방어 보너스 제거, UI 문구

호환성
- 기존 도시 단계 I/II/III, 건물 해금, 토성 Lv/내구/재건축, STEPPE, 수도, 장수 시스템 유지.
- v120의 토성 투명 배경 이미지도 누적 포함.

검증 항목
- JS 문법 검사
- 군사도시 이동 AP 최소 1
- 농업도시 모집 병량 20% 절감
- 농업/해상 병량 생산 배율
- 상업도시 특산품 생산 x2
- 해상도시 교역가치 x1.5
- 기존 군사도시 방어 보너스 제거 코드 존재
- UI 신규 설명 문자열 및 신규 규칙 스크립트 로딩 확인
