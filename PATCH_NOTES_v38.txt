삼국쟁패 v38 · 문/무관 아이콘 줌 스무딩 리팩터링

[원인]
- 기존 v37까지는 휠마다 zoomMap -> setView -> drawMap 순서로 SVG 전체를 즉시 다시 그림.
- drawMap 직후 관직 아이콘 레이어가 제거되고 다음 RAF에서 다시 만들어져 1프레임 크기/표시 튐이 발생할 수 있었음.
- 스케일 보간 수식은 존재했지만 카메라 viewBox가 계단식으로 먼저 바뀌어 목표값 자체가 불연속적으로 점프함.

[v38 구조]
1. SmoothMapZoomController.js
- wheel/줌 버튼 이벤트에서는 targetView만 변경.
- 실제 mapView/viewBox는 requestAnimationFrame Update에서 프레임 독립 지수 Lerp로 추적.
- cameraSmoothingSpeed = 11.
- 빠른 휠 입력은 현재 targetView에 누적되어 이벤트 폭주에도 drawMap을 반복하지 않음.
- 정규화 오차 0.001 미만이면 목표값에 정확히 스냅하고 RAF 종료.
- 드래그 시작 시 남은 줌 관성 즉시 취소.
- 수렴 완료 후 drawMap은 딱 1회만 실행.

2. OfficerMapZoomScaler.js
- map-view 이벤트는 목표 스케일/알파만 기록하며 SVG transform을 즉시 변경하지 않음.
- 실제 文/武 아이콘 transform은 RAF Update에서만 갱신.
- smoothingSpeed = 10, opacitySmoothing = 12.
- deltaTime은 1/240~0.05초로 제한해 탭 복귀/프레임 드랍 점프 방지.
- 정규화 차이 0.001 미만이면 정확한 목표값으로 스냅해 미세 진동 제거.
- 기존 줌 아웃 culling 1.05 / 재표시 1.12 히스테리시스 유지.
- 최대 확대 상태는 기존 40px 목표 크기 유지.

3. OfficerMapIconController.js / MapZoomUIBridge.js
- drawMap으로 SVG가 교체되어도 아이콘을 같은 JS turn 안에서 즉시 재생성.
- 새 DOM에는 이전 프레임의 보간 상태를 paint 전에 이식해 기본 크기 1프레임 노출을 차단.
- CSS transition은 제거하고 RAF 보간기 하나만 transform을 소유해 이중 보간/충돌 방지.

[튜닝]
OfficerMapZoomConfig.js에서 아래 값을 조정할 수 있음.
- smoothingSpeed: 10.0 (아이콘 크기 반응)
- opacitySmoothing: 12.0 (숨김/표시 페이드)
- cameraSmoothingSpeed: 11.0 (월드맵 줌 추적)
- deadzone / cameraDeadzone: 0.001
- minIconPx: 29 / maxIconPx: 40
- hideBelowZoomRatio: 1.05 / showAboveZoomRatio: 1.12
