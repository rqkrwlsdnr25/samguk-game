삼국쟁패 v125 — 월드맵 동/남 확장 + 읍루/동진/왜 세부 거점 + 섬 노드/해상 경로 패치

[기준]
- 사용자 업로드: 124백업.zip
- 기존 좌표계/영토 렌더 방식(SVG path + WORLD.territories + WORLD.neighbors + WORLD.seaRoutes)을 그대로 유지합니다.
- 기존 0~101 영토 ID는 절대 변경하지 않고, 신규 영토만 102번부터 뒤에 추가합니다.
- 대마도(100)의 왜구 전환 로직도 기존 ID를 유지하므로 깨지지 않습니다.

[적용 결과]
1. 월드맵 경계 확장
- 동쪽 maxX: 1260
- 남쪽 maxY: 1390
- WorldMapBoundsController가 신규 polygon path를 읽어 전체 view / pan / zoom 범위를 자동 확장합니다.

2. 신규 세부 거점 19개
- 읍루 확장 4개: 읍루 극동 북부, 읍루 동북 해안, 읍루 극동 중부, 읍루 동해안
- 왜 확장 6개: 왜 동북부, 왜 극동부, 왜 중부 동부, 왜 기내 동부, 왜 남부, 왜 남동부
- 동진 확장 6개: 동진 강남 서부/중부/동부, 동진 남해 서부/중부/동부
- 섬 노드 3개: 이키섬, 오도열도, 오키섬

3. 섬/해상 그래프
- 기존 우산/대마도/탐라 노드는 그대로 유지합니다.
- 신규 이키섬/오도열도/오키섬을 선택/점령 가능한 영토로 등록합니다.
- WORLD.seaRoutes + WORLD.neighbors에 해상 Edge를 동시에 등록합니다.
- canMoveSeaRoute(i,j)를 추가해 실제 등록된 해상 Edge만 true를 반환합니다.
- map.js의 기존 해상 점선 렌더러를 그대로 재사용하고 drawSeaRoutes() API를 추가합니다.

4. 구버전 저장 호환
- v124 이전 저장본은 regions 길이가 102개이므로 신규 월드 121개와 불일치합니다.
- restoreTurnSnapshot()에서 기존 102개 상태는 그대로 복원하고 신규 19개 영토만 기본 상태로 보충합니다.

5. 지형 룰 호환
- TERRAIN_RULES_DATA.areas를 신규 영토 수까지 확장합니다.
- 신규 영토는 기본 plain, 일부 동진 확장 영토는 river=true로 설정합니다.
