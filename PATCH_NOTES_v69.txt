삼국쟁패 v69 · 시작 세력 선택 시네마틱/VFX

기준: v68 섬 도시 50% 축소 전체본

추가 기능
1. 세력 카드 선택 시 SelectionMode 전환.
2. 좌측 군주 대형 초상 노출 및 선택 변경 크로스페이드.
   - 별도 PNG가 있으면 window.SAMGUK_RULER_PORTRAITS 매핑을 우선 사용.
   - 현재 패키지에는 별도 군주 PNG가 제공되지 않았으므로 기존 군주 생성 SVG를 고해상도 확장 fallback으로 사용.
3. 선택 세력 초기 영토 전체를 자동 계산해 카메라 Auto-Fit/Lerp.
   - 선택창이 중앙을 가리는 점을 고려해 영토가 우측 지도 영역에 보이도록 화면 중심을 약간 오른쪽으로 바이어스.
4. 비선택 세계/바다 차콜 암전 + 선택 영토 컷아웃.
5. 선택 영토 union 마스크 기반 외곽 Aura/Glow.
6. 국가 외곽 경계선을 따라 흐르는 광입자 + 작은 비산 Spark 파티클.
7. VFX는 선택창이 열려 있을 때만 requestAnimationFrame 실행하고 닫히면 즉시 중단.
8. VFX 전용 Canvas DPR을 픽셀 예산 기준으로 제한하여 고해상도 모니터에서도 과도한 GPU 사용 방지.
