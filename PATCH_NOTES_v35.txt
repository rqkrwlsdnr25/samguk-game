삼국쟁패 v35 — 국가별 인물 스타팅 재편

1. 기존 인물 자동배치 초기화
- 기존의 '모든 영지에 문관+무관 2명, 수도 추가 1명' 생성 로직 제거.
- OFFICER_PRESETS 초기화.
- 새 게임 시작 시 roster / id index / territory index를 모두 비운 뒤 새 규칙으로 재생성.

2. 수도 스타팅 3인
- 초기 영지를 보유한 각 국가의 수도에 정확히 3명 배치.
  · 군주 1명: 무력/통솔/지력/매력 모두 평균 이상.
  · 대장군 1명: 무력 또는 통솔 90~99 특화.
  · 재상 1명: 지력 또는 매력 90~99 특화.
- 고정 ID: core-{국가ID}-king / general / chancellor.

3. 비수도 영지 수비무관
- 각 비수도 초기 영지에 일반 무관 1명만 배치.
- 무력 45~70, 통솔 48~70. 두 능력치는 코드상 Math.min(70, ...)로 이중 제한.
- 지력/매력은 낮은~중간 범위로 설정해 수도 핵심 인물과 역할 차별화.
- 고정 ID: guard-{영지ID}.

4. 4대 스탯 데이터 모델
- 캐릭터 기본 데이터는 War(무력), Lead(통솔), Int(지력), Cha(매력) 4개만 열거.
- 기존 시스템의 '정치' 참조는 저장 데이터에 포함되지 않는 호환 getter로 처리.
- 호환 내정 수치 = round((지력 + 매력) / 2).
- 장수 상세 UI도 5대 능력치 -> 4대 능력치로 변경.

5. 안전장치
- 턴 롤백 복구 시 stats 객체의 호환 getter를 자동 재부착.
- roster 배열과 Map 객체는 재할당하지 않고 clear/splice 방식으로 갱신하여 기존 UI/API 참조를 유지.
- 생성 직후 국가 수도 3인 / 비수도 1인 / 수비무관 무력·통솔 <=70을 검증.
- 초기 영지가 0개인 세력은 인물 생성 대상에서 제외하고 콘솔 경고를 남김.

현재 맵 데이터상 '거란'은 초기 영지가 0개이므로 기존 게임 로직에서도 시작 불가 세력입니다. 영지를 배정하면 생성기가 자동으로 해당 수도(첫 초기 영지 fallback)에 3인을 생성하도록 되어 있습니다.
