삼국쟁패 v92 - 장수 상세 정보 모달 전면 개편

- 토탈워 삼국 계열 감성의 좌측 대형 초상 + 우측 정보 레이아웃으로 변경
- 5대 능력치: 통솔 / 무력 / 지력 / 매력 / 권위 추가
- 권위는 기존 4스탯 기반 파생 기본값을 갖고, 장수 데이터에 authority가 있으면 해당 값을 우선 사용
- 장수 데이터에 title / salary / age / traits / portraitUrl 필드 추가
- 기존 4스탯 UI 박스와 지휘 계산 중심 레이아웃 제거
- 기존 기술/군사/관계식 하단 구성 대신 특성 목록 + 실제 효과 설명 중심으로 변경
- 기존 전법(skill) 데이터를 특성 리스트에 재사용하여 실제 게임 효과 설명 표시
- 포로 성향(강직/중용/유연)의 등용 보정을 특성으로 표시
- 태수일 경우 태수 효과를 특성 항목으로 추가 표시
- 병과 적성은 컴팩트 표시 유지
- 담당 보직 변경과 계략 실행 기능은 하단 명령 영역으로 보존
- 부상 시 신규 권위 스탯도 기존 주요 능력치와 함께 50% 감소 후 회복
- 기존 지도/전쟁/도시/외교/장수 카드/포로 시스템 유지
