삼국쟁패 v74 - 4단계 왕권 / 권위(Prestige) 시스템
기준: v73 점령·공성 연기 VFX 최적화 전체본

[신규]
- 왕권 4단계만 사용: 지방왕(0) -> 왕(100) -> 대왕(300) -> 황제(600)
- 권위 획득: 전투 승리 +20 / 일반 건설 완료 +10 / 수도 증축 완료 +50
- 영토 행동 패널에 [왕권] 탭 추가
- 수묵화 스타일 세로 4단계 왕권 UI + 단계별 ProgressBar
- Rank-Up 중앙 플래시 VFX + WebAudio 저음 북소리 3타

[글로벌 버프]
- 왕: 모집량 x1.30, 영토 수입 x1.30, 대장군/재상 임명권 API 해금
- 대왕: 최대 행동력 +2, 속국/공물 요구 dealScore +15
- 황제: 최대 행동력 추가 +3 (왕권 총 +5), 속국/공물 요구 +25, 천하통일 챌린지
- 황제 챌린지: 턴 종료 후 생존 AI 세력과 우호도 -2

[연동]
- 기존 fight()/finishLargeBattle() 결과에 승리 권위 연결
- 기존 performBuild() 성공에 건설 권위 연결
- 기존 upgradeCapital() 성공에 수도 증축 권위 연결
- 기존 territoryIncome/recruitAmount/actionLimit을 보존한 상태에서 파생 multiplier/bonus를 마지막 단계에 곱/가산
- 기병/특수병 모집에도 왕 작위 모집 보너스 적용
- AI 일반 모병에도 왕 작위 모집 보너스 적용
- DiplomacyTradeSystem의 종속국/공물 요구에 대왕/황제 가중치 적용

[주의]
- 기존 게임에는 별도의 6단계 왕권 데이터가 존재하지 않아 삭제할 레거시 왕권 객체는 없었습니다.
- 기존 수도 증축, 도시 증축, 건설, 전투, 장수, 외교 데이터 구조는 삭제/재작성하지 않았습니다.


최종 검증 보강

- window.SAMGUK_AUTHORITY_SYSTEM에서 최고 관직 임명권/외교 요구 보너스 조회 API 노출.
