삼국쟁패 v78 - 내정/모병 UI 가독성 개편

기준: v77 왕권 UI 렌더 오류 복구 전체본

변경 사항
1) 상단 행동 버튼 기능별 테두리 색상
- 지원/침략: 적갈색
- 내정/도시증축/수도증축: 금색
- 인사: 청색
- 첩보/계략: 보라색
- Hover/선택 상태 하이라이트 추가
- 기존 data-mode / 클릭 이벤트는 변경하지 않음

2) 모병 슬롯 콤팩트화
- 기존 모집 버튼 ID와 data-recruit-unit 유지
- 병과 버튼 높이 축소
- 버튼 아래 효과 설명을 한 줄 레이어로 분리
- 모병, 기병, 궁병, 해병, 국가 고유 병과 모두 동일 구조 적용

3) 특산품 UI 우측 영토 정보창 이동
- 내정/모병 패널 아래 resourceUI 제거
- 선택 영토 #detail에서 terrainInfo 바로 위에 렌더링
- 기존 자원 효과 수치/궁전 버튼 동작 유지
- 기존 요약의 중복 '특산품:' 텍스트 제거
- 은은한 골드 Glow/Sweep 테두리 효과 추가

수정 파일
- game.js
- unit-rules.js
- resources.js
- index.html
- ui-panel-polish-v78.css (신규)

기존 6개 행동 버튼의 이벤트/게임 로직은 변경하지 않음.
