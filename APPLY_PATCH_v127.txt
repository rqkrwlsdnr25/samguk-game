삼국쟁패 v127 — 일본 확장부 Blue Mask 완전 제거 / 해안선 클리핑 패치

[적용 기준]
- 기준 버전: v126
- 사용자 가이드 이미지의 순수 파란색 마스킹 영역을 실제 좌표계로 역산해 바다로 제거
- 빨강/흰색 가이드 경계 기준으로 확장 일본 영토 Polygon을 클리핑
- 영향 영토: 왜 동북부 / 왜 극동부 / 왜 중부 동부 / 왜 기내 동부 / 왜 남부 / 왜 남동부
- 파란 영역을 건너던 일부 육상 neighbor 연결 제거
- 각 영향 영토의 center(x,y)를 남아 있는 주황색 육지 내부로 재배치
- 기존 0~101 좌표계, 카메라 비율, 섬/해상루트, 읍루/동진 확장 데이터 유지

[수정 파일]
- MapExpansionV125.js

[적용 방법]
1. 아래 패치 ZIP을 v126 게임 폴더에 압축 해제합니다.
2. MapExpansionV125.js를 기존 파일 위에 덮어씁니다.
3. 브라우저 캐시를 강력 새로고침(Ctrl+F5)한 뒤 확인합니다.

[검증]
- 전체 영토 121 / neighbors 121 일치
- v127 geometryRevision = v127-blue-mask-coastline-clip
- 6개 영향 Polygon 모두 SVG/기하 유효성 통과
- 6개 center 모두 자기 Polygon 내부 위치 확인
- 사용자 Blue Mask와 6개 영향 Polygon의 교집합 면적 = 0
- Node.js 문법 검사 통과
