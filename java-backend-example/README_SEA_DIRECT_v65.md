# v65 직접 해상 연결 서버 연동 참고

`DirectSeaAdjacencyConfig.apply(adjacency)`를 서버 그래프 초기화 직후 호출하면 중간 SeaNode 없이 아래 연결이 양방향 인접 간선으로 등록됩니다.

- 산둥반도(40) ↔ 한성(8)
- 산둥반도(40) ↔ 웅진 서부(9)
- 산둥반도(40) ↔ 탕정성(66)

이 간선은 `SeaMovementPolicy.RouteKey`에도 동일하게 등록할 수 있습니다. 바다 위 정박/주둔 상태는 만들지 않으며, 바다는 이동 중간 표현일 뿐 출발/도착 노드는 육지 영토만 사용합니다.
