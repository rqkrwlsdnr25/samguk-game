# v74 Authority / Prestige backend example

기존 `Faction` 객체에 `FactionRank` / `authorityScore`를 추가하고, 기존 객체를 그대로 전달해 상태만 갱신합니다.

임계값: 지방왕 0 / 왕 100 / 대왕 300 / 황제 600.

획득 이벤트:
- 전투 승리 +20
- 일반 건설 완료 +10
- 수도 증축 완료 +50

버프:
- 왕 이상: 전역 모집량 x1.30, 경제 수입 x1.30, 대장군/재상 임명권
- 대왕 이상: 최대 행동력 +2, 속국/공물 요구 가중치
- 황제: 대왕 +2에 추가 +3 = 총 +5, 천하통일 챌린지
- 황제 챌린지: 생존 AI와 우호도 매 턴 -2

실게임 JS는 수치를 원본에 영구 곱해 중복시키지 않고 현재 작위에서 파생된 multiplier를 계산합니다. 따라서 저장/로드나 재렌더 시 1.3 배율이 중복 적용되지 않습니다.
