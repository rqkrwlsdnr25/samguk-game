삼국쟁패 v32 — 문관/무관 아이콘 줌 컬링 + 스무스 스케일 패치

1) Zoom-Based Culling
- zoomRatio = WORLD.width / 현재 viewBox 폭
- zoomRatio <= 1.05: 아이콘 숨김
- zoomRatio >= 1.12: 아이콘 다시 표시
- 숨김/표시 임계값을 분리한 히스테리시스로 경계 깜빡임 방지

2) Smooth Scale Interpolation
- 즉시 transform 갱신을 제거하고 requestAnimationFrame 기반으로 통합
- alpha = 1 - exp(-smoothing * deltaTime) 지수 보간 적용
- 프레임레이트와 무관하게 부드러운 크기/오프셋/알파 변화
- deltaTime은 1/240~0.05초로 제한하여 휠 폭주/탭 복귀 시 점프 방지

3) Maximum Zoom Visibility
- 줌 인 시 목표 픽셀 크기는 최대 40px로 수렴
- zoomRatio >= 4.0에서 40px로 고정
- SVG 레이어를 항상 최상단 렌더 순서로 유지

4) Safety / Performance
- NaN/Infinity 방지 finite + clamp
- 연속 wheel 이벤트를 RAF 1회로 합침
- 값이 목표에 수렴하면 RAF 자동 종료
- drawMap() 재생성 후 레이어 자동 복구 유지

튜닝은 OfficerMapZoomConfig.js에서 가능.
