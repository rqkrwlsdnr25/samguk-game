기준 버전: v136

적용 내용
1. 동진 기본 영토 재분할
- 동진 내륙: 기존 외곽 유지, 공유 경계 정렬
- 동진 연안: 신규 하천 북쪽 연안 영역으로 확장/정리
- 동진 남부: 빨간 가이드 상단/서측 기준으로 재분할
- 동진 남동: 빨간 세로 경계 기준으로 재분할

2. 강남 영토 정리
- 동진 강남 서부 / 동진 강남 동부 2개 영토로 정리
- 동진 강남 중부 / 동진 남해 서부 / 동진 남해 중부 / 동진 남해 동부 확장 노드는 v137에서 생성하지 않음

- 강남 동부 동쪽 해안 wedge를 Polygon 자체에서 제거

- DongjinMapDataV137.js의 river.path를 데이터 소스로 사용
- 밝은 물빛 halo + 청색 본선의 2중 SVG stroke

5. 데이터 구조
- DongjinMapDataV137.js / DongjinMapDataV137.json으로 동진 geometry 독립 관리
- MapExpansionV125.js는 해당 데이터를 로드해 WORLD.territories에 적용
- 기존 일본 v134 및 읍루/연해주 v136 데이터는 유지

- ZIP 내부 파일을 현재 v136 게임 폴더에 폴더 구조 그대로 덮어쓰기
