삼국쟁패 v52 - 하단 외교 / Canvas 관계선 / 상호 거래 패치
기준: v51 화질흐림 GPU 캐시수정 전체본

1) 외교 UI를 화면 하단 약 30~32% 트레이로 재배치
- 상단/중앙 지도 노출 면적 확대
- 양 군주 카드도 하단 좌/우로 축소 배치
- 기존 외교 기능은 유지

2) HTML5 Canvas 외교 관계 화살표
- 플레이어 수도 ↔ 선택 상대 수도를 화면 좌표로 연결
- 전쟁 #FF0000 / 동맹 #0000FF / 중립 #FFFFFF
- 대시가 흐르는 곡선 애니메이션
- 줌/팬 중 매 프레임 수도 위치를 다시 읽어 화살표가 따라감

3) '요구 전달' → '요구 제안'
- 내가 주는 것: 금/병량/병력/공물
- 내가 요구하는 것: 불가침/교역/동맹/공물/영토/종속국
- 중앙 거래 조건표 + 제안 균형/성사 가능성 표시
- 성사 시 실제 금/병량/병력/조약/영토 상태 반영

4) Java 백엔드 예시 분리
- java-backend-example/ 아래 DTO/enum/session store/service 추가
- 현재 정적 게임은 JS만으로 정상 실행, 서버 연동 시 해당 모델 사용 가능
