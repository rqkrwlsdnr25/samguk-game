[핵심 변경]
◆ 군사도시
- 출병/공격 이동 행동력 비용 -1, 최소 1 보장
- 적 전문도시/수도/가동 중 토성 공격 시 공격 전력 +30%
- 해당 군사도시에서 출병하는 지휘 장수: 무력 +5 상당 공격 보정
- 해당 군사도시에서 출병하는 지휘 장수: 통솔 +5 상당 최대 출병 병력 보정
- 기존 군사도시 자체 방어력 보너스 제거 → 토성과 역할 완전 분리

◆ 농업도시
- 해당 영토 턴 병량 생산 +50%
- 해당 영토에서 보병/기병/특수병 모집 병량 비용 -20%
- 데이터 규칙에 보충 병량 계수 0.80도 함께 정의
- 기존 농업도시 징집량 직접 증가 효과 제거

◆ 상업도시
- 해당 영토 턴 금 수입 +50%
- 해당 영토 특산품 생산량 2배

◆ 해상도시
- 해당 영토 턴 금 수입 +25%
- 해당 영토 턴 병량 생산 +25%
- 외교 특산품 교역가치 +50%
  ※ 현재 특산품 재고가 정수 단위이므로 실제 거래 수량을 1.5개로 만들지 않고 협상 가치에 +50%를 적용합니다.

◆ 토성
- 기존 수비 전용 역할 유지
- Lv.1 +30% / Lv.2 +50% / Lv.3 +70%
- 기존 내구 3회 / 파괴 / 재건축 시스템 유지
